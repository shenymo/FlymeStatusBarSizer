# FlymeStatusBarSizer

让 Flyme 的系统界面更合心意。**FlymeStatusBarSizer** 是一个面向 Flyme 的 LSPosed 模块，应用名称为 **FlymeBarSizer**。首页支持功能搜索，部分设置提供预览。

[下载 APK](https://github.com/shenymo/FlymeStatusBarSizer/releases) · [反馈问题](https://github.com/shenymo/FlymeStatusBarSizer/issues) · [开源许可](LICENSE)

## 功能

### 状态栏图标与电池

- 调整状态栏图标、电池数字及通知图标大小；通知可使用应用自身图标，并可下载和管理通知单色图标库。
- 分别隐藏 24 类系统状态图标，包括连接网络、声音提醒、定位、同步和系统状态图标，并释放图标占位。
- 自定义电池图标样式、数字字体、镂空效果、宽高、圆角和电池帽；可改用摄像头环形电池，调整大小、粗细、颜色、透明度及动画。
- 自定义移动信号柱和双卡显示、网络类型文字、Wi-Fi 图标样式及图标顺序。

### 时间与网络

- 组合状态栏时间，支持秒、星期、AM/PM、传统时辰及顺序、字重和字号调整。
- 点击时钟查看日期、农历、内存、电池、最近任务和快捷入口。
- 设置网速显示与隐藏阈值及确认次数；调整时间、日期、网速、锁屏运营商和原生电量数字的字体大小与粗细。

### 系统外观与桌面

- 前置摄像头空闲时隐藏软件绘制的黑边；分别设置桌面、最近任务、通知栏、控制中心和锁屏的状态栏图标颜色。
- 在桌面分页指示器上左右滑动切换页面。
- 使用 AI 按应用用途整理桌面图标和文件夹，支持选择范围、预览、调整和应用；也可按使用频率整理文件夹内应用。
- 调整通知卡片和最近任务卡片外观；自定义桌面文件夹背景色及 Aicy 入口。

### 系统交互

- 自定义 mBack 长按动作，包括打开 URL / Intent、时间弹窗和后台应用星图；调整导航栏透明度、小白条显示和尺寸。
- 配置侧边手势的触发边、距离、时长和场景，可打开全局 Aicy 纵览、快捷工具面板或进入应用单手缩放工作台；Aicy 支持背景、模糊和顶部颜色设置，工作台支持最近任务切换和键盘避让。
- 调整小窗侧边手势、选择面板环数及长停全屏行为。
- 自定义底部下滑模式和应用单手模式。
- 将返回、粘贴、撤销、删除、全选、复制、切换输入法等按钮编排到输入法控制栏。
- 启用 iOS 式堆叠最近任务，调整卡片布局、手势、动画、模糊、阴影及性能参数。
- 扩展 CarLink 应用流转，提供网易云首次加载修复和车机昼夜样式隔离选项。

### 分享与系统工具

- 分别管理图片、视频、文本、PDF 和音频的系统分享列表，可隐藏入口、拖动排序、置顶或恢复系统顺序；支持 Flyme 图库分享面板。
- 微调时钟、电池、移动网络、Wi-Fi 和输入法控制栏位置，以及环形电池位置。
- 模拟 SIM 数量、默认上网卡、网络类型和信号等级，用于图标调试。
- 提供验证码识别诊断、性能日志、OneMind 性能调节控制和手机管家后台优化。
- 导入、导出配置或恢复默认设置。

功能是否可用会受机型、Flyme 版本和对应系统组件影响。

## 使用前提

- Flyme 系统设备，并已获取 Root 权限。
- 已安装并启用支持 **libxposed API 101** 的 LSPosed。

## 安装与启用

1. 从 [Releases](https://github.com/shenymo/FlymeStatusBarSizer/releases) 下载并安装 APK。
2. 在 LSPosed 中启用模块，并勾选所需系统组件作用域。
3. 首次启用后重启手机，再打开 **FlymeBarSizer** 设置功能。
4. 设置通常会自动保存；部分编辑器需点击“应用”，部分功能需重启对应组件后生效。

常用作用域：`com.android.systemui`（状态栏和系统交互）、`com.meizu.flyme.launcher`（桌面和最近任务）、`com.android.intentresolver`（系统分享）。图库、Aicy 纵览、输入法及其他 Flyme 组件功能还需启用各自作用域。

## 构建

需要 JDK 17 和 Android SDK 36：

```bash
./gradlew :app:assembleRelease
```

APK 输出于 `app/build/outputs/apk/release/`。

## 注意

模块依赖 Flyme 系统组件，不同设备和系统版本的兼容性可能不同。修改系统界面前，请确认了解如何在 LSPosed 或 Recovery 中停用模块。
